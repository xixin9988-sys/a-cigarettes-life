# A Cigarette's Life / 《香烟的一生》

A 2D top-down, probability-driven living-world life simulation. You are an anthropomorphic
cigarette living in Willowbrook village and Ashford City. The world keeps running while you
are away: NPCs work, socialise, spend money, relationships evolve, shops trade, crops grow,
weather changes, and events unfold.

See `docs/ARCHITECTURE.md` for the system design and `docs/AGENT_TASKS.md` for the module map.

## Commands

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # typecheck + production build
npm run test       # vitest
npm run lint       # eslint
npm run typecheck  # strict TS for app + worker projects
```
